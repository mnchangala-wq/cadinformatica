# Pendientes

PWA para guardar tareas pendientes desde el celular (iPhone) y pasarlas a Google Calendar.

- Datos guardados localmente en el dispositivo (localStorage).
- `?text=...` en la URL agrega una tarea (para usar con un Atajo de iOS desde la hoja de compartir de WhatsApp).
- Botón «Calendar» abre Google Calendar con título y descripción precargados.

## Uso
Publica los archivos con cualquier hosting estático con HTTPS (GitHub Pages, por ejemplo),
abre la URL en Safari y usa Compartir → Añadir a pantalla de inicio.
